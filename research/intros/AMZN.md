# AMZN — Amazon.com, Inc.（亚马逊）
更新：2026-11-13｜数据来源：research/theses/AMZN.md + 公司 Q3 财报及媒体报道。标"约/未核实"的不要当精确数用。

## 一句话
表面是全球最大的网上商店，真正赚钱的是"云计算房东" AWS 和广告；现在正把巨额现金砸进 AI（人工智能）数据中心。

## 公司是做什么的
- 1994 年由贝索斯创立，最早在网上卖书；总部在美国西雅图。
- 业务：电商（自营 + 第三方卖家平台 + 物流）、Prime 会员（含视频、音乐）、AWS（亚马逊云服务，出租算力和存储）、广告、自研芯片 Trainium（AI 训练芯片）、Alexa 语音助手等。
- 规模：Q3（第三季度）2026 单季营收 $2019 亿，同比 +12%。
- 生活化类比：它像一座超大城市的"商场 + 快递公司 + 发电厂"。商场（电商）人流巨大但利润薄；发电厂（AWS）把电卖给全城的工厂，利润厚；商场里的广告牌（广告）几乎是纯利润。

## 怎么赚钱（Q3 2026，按分部）
| 分部 | 营收 | 同比 | 营业利润 | 营业利润率 |
|---|---|---|---|---|
| 北美（电商等） | 约 $1129 亿 | 约 +6% | $87 亿 | 7.7%（一年前 4.5%） |
| 国际（电商等） | $431 亿 | +5%（不计汇率 +8%） | $16 亿 | 3.7% |
| AWS | $460 亿 | +39%（近 5 年最快） | $178 亿 | 约 38.7% |
- AWS 收入约占 23%，但贡献了约 63% 的营业利润（$178 亿 / $281 亿）。
- 广告收入 $196.4 亿，+11%（不计汇率 +12%），算在北美/国际里；Prime Day 今年挪到 Q2，拉低了 Q3 增速（Prime Day 若仍在 Q3，总营收增速约多 4 个百分点）。Q4 广告预计增长"高十几个百分点"。
- 订阅、第三方卖家服务等分项本次未查到。
- 客户：几亿消费者；数百万第三方卖家；AWS 客户从初创公司到大企业、政府和 AI 公司。

## 护城河 & 竞争对手
- 护城河：①物流网络（仓库、配送）十几年、上千亿美元建成，对手难复制；②Prime 会员锁定高消费用户；③AWS 先发优势 + 庞大企业客户迁移成本高；④购物搜索广告：用户"带着钱包来搜"，广告转化率高；⑤自研芯片（Trainium、Graviton）降低成本。
- 竞争对手：电商——沃尔玛、Temu、Shein、TikTok Shop；云——微软 Azure、谷歌云（Q3 +103%，增长更快）、甲骨文；广告——谷歌、Meta。
- 注意：谷歌云和 Azure 增速都高于 AWS，AWS 的市场份额在被追赶，但绝对规模仍最大。

## 关键人物和近期大事
- Andy Jassy：CEO（前 AWS 负责人）。Matt Garman：AWS CEO；Brian Olsavsky：CFO（这两人为训练资料信息，未在本次核实）。贝索斯为执行董事长/大股东（未核实当前持股）。
- 10-29 Q3 财报：营收略低于预期，EPS 也略低；但 AWS 增速和营业利润率创新高。盘后跌约 7%，随后靠 AWS 叙事收复。Jassy 预计 AWS 2027、2028 年增速都在 40% 以上（管理层展望）。
- AWS 积压订单：有报道称约 $5780 亿，未核实（新闻稿里没有，可能来自电话会）。
- Trainium 计划 2027 年底开始对 AWS 以外客户销售（据报道）。
- 11-02 Phillip Securities 上调到买入，目标价 $330；11-09 JPMorgan 把 AMZN、META 列为首选互联网股，当天 +5% 以上。
- 高管减持：Jassy 等近期减持/行权；有来源称约 $45 亿，金额明显存疑，未核实。
- 11 月 AWS 新品：AgentCore Runtime V2（AI 智能体运行平台）等。

## 关键财务数字（Q3 2026）
- 营收 $2019 亿，+12%；营业利润 $281 亿，+61%；营业利润率 13.9%，史上最高。
- EPS（每股收益）$1.89，预期 $1.96。
- capex（资本开支）单季 $773 亿；2026 全年约 $2200 亿；2027 年"明显更多"。
- FCF（自由现金流）过去 12 个月约 −$424 亿（一年前约 +$148 亿）。
- Q4 指引：营收 $2400–2470 亿，营业利润 $285–335 亿。
- 估值：现价 $267.46，PE（市盈率）约 21.5x（可能含投资收益，未核实），远低于亚马逊历史上常见的 30–60x。因为亚马逊长期把利润再投资，用 PE 看它一直偏贵，更常用"营业利润"或"现金流"倍数估值。

## 主要风险
1. capex 远超经营现金流，FCF 深度为负，可能要发债。
2. AI 需求一旦降温，最先被质疑的就是这些数据中心投资。
3. AWS 被谷歌云、Azure 追赶，增速若跌回 30% 以下，故事就变了。
4. 零售增速只有个位数到 10% 左右；Temu、TikTok Shop 等低价竞争。
5. 反垄断（FTC 起诉）、集体诉讼、数据中心政策收紧（细节未核实）。

## 我的 vision（3–5 年）
- 乐观：AWS 保持 40% 左右增长，Trainium 成为英伟达之外的主力 AI 芯片；广告继续高增长、零售利润率稳步提升；2028 年 capex 见顶后 FCF 大幅回正，股价有望 $350–400。
- 基准：AWS 30–40% 增长，零售利润率缓慢改善，FCF 1–2 年后转正；估值按营业利润 22–28 倍，股价随利润每年涨约 10–15%。
- 悲观：AI 算力供过于求，AWS 价格战、增速下滑，巨额 capex 变成折旧负担；零售被低价平台挤压；股价可能回到 $180–200。
- 为什么买入区间是 $240：合理价值 $240–300（年化营业利润约 $1200–1300 亿 × 22–28 倍）。$240 是区间下沿，也接近 60 日低点 $240、比我们成本 $247.29 低约 3%。现价 $267 接近高位，不追；而且回落必须是市场/行业原因，不是 AWS 失速。
- 组合角色：核心股，低点买入、永不卖、不止损。它是组合里"AI 基础设施 + 消费"的双轮下注，和 GOOGL（搜索 + 云）、META（纯广告）互补；选举后大跌日相对抗跌（据 thesis）。

## 本篇缩写表
- AWS：亚马逊云服务（Amazon Web Services），出租服务器、存储和 AI 算力。
- AI：人工智能。
- EPS：每股收益，净利润 ÷ 股数。
- capex：资本开支，建仓库、数据中心、买服务器的钱。
- FCF：自由现金流，经营现金流减去 capex。
- PE：市盈率，股价 ÷ 每股收益。
- FTC：美国联邦贸易委员会。
- CEO / CFO：首席执行官 / 首席财务官。
- Q2/Q3/Q4：第二/三/四季度。
