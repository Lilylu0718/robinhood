# 教训（每次研判必读；每周复盘更新，≤25 条）

1. **2026-11-12 NVDA**：公司自身危机（CEO 调查/丑闻）未落地时，按跌幅+RSI 两次机械加仓（11-06、11-09），之后继续下跌至 -11%；11-12 CEO 辞职。
   → 公司自身风险未落地时，不按跌幅加仓；等事件落地 + 价格企稳。跌得深 ≠ 便宜。
   → （11-12 周复盘补充）**董事会对 CEO/高管启动调查的当天，就算"未落地的公司自身风险"**，立即把该标的设 paused；不能因为分析师说"需求不受影响"、或总统/媒体为其辩护就当成"只是治理新闻"放行。

2. **2026-11-12 AVGO vs NVDA**：11-05 选举后板块恐慌（纳指100 单日 -6.4%，SOX -12%），11-06 买 AVGO（无公司自身新闻）→ 一周 +19%；同期 NVDA（公司出事）-11%。
   → 指数/板块单日 ≤-5% 且个股**没有自身负面新闻**时，1-2 天内买入质地最好的核心股是对的；先区分"板块恐慌"（可以抄）还是"公司出事"（等落地）。
   → （11-13 周复盘补充）同样适用于受保护的卫星（MU）：11-06 MU 收 690（低于成本 -19%，纯板块恐慌）没加，一周后 778（+12.8%）。

3. **2026-11-12 NVDA 一周 3 次买入**：11-03、11-06、11-09 三次买 NVDA，6 天内把单只推到仓位上限附近，平均成本仍被击穿。
   → 同一标的 7 天内最多加仓 1 次，除非出现新的正面基本面证据（财报超预期、风险落地）。下跌途中留子弹给"事件落地后"。

4. **2026-11-13 现金闲置**：本周现金占 36–51%，QQQ +3.6% 而组合 +1.3%；11-09~11-12 入金 $1000 一直没动。现金是为 NVDA 财报留的事件储备，这本身对，但 51% 远超一个事件需要的量。
   → 现金分两部分：**事件储备 ≤25% 总值**（写清给哪个事件、哪个分支）；超出部分在 5 个交易日内必须有去向——分 2-3 批买入离买入线最近、无自身风险的标的，或在 QQQ 合理区间下沿附近买 QQQ。每次运行都要回答"超额现金为什么还没花"。

5. **2026-11-13 半导体集中度**：NVDA/AVGO/MU 合计约占总值 28%、持仓的 58%，11-05 和 11-13 都是一起跌。
   → **半导体（含 TSM/ASML 等）合计 ≤40% 总值**；同一时期只加其中一只；指数大跌日优先买非半导体核心股（GOOGL/MSFT/META）或非科技卫星（BKNG/NFLX）。
