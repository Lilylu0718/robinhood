# 策略设计：完整讨论（调整策略逻辑时再读）

标的池：AVGO / NVDA / MU / QQQ（沿用已有观察名单，而不是扩大到陌生股票——策略不理想时至少能分清是"策略问题"还是"标的问题"）。

> 2026-09 更新：数据源全部改为 Robinhood Agentic Trading MCP，不再用 yfinance / Finnhub / NewsAPI。下面括号里标了对应的 MCP 工具。

## 四层信息来源（不构成推荐，仅为行业常见思路）

**3.1 技术面**：动量突破 / 均值回归 / 均线交叉。数据源 `get_equity_historicals`（OHLCV bars，split-adjusted）；也可参考 `get_equity_technical_indicators` 的预计算指标做交叉验证。

> 2026-09 定稿的入场/离场不对称：**入场只认"新金叉"事件**（不追已在多头排列的票）；**离场是状态判断**——持仓且 MA10 < MA30 就走，不等新的死叉。理由：漏跑一天不该把仓位困在下跌里干等 -6% 止损。入场严格、离场宽松。

**3.2 基本面/财报层**：财报日历避雷（`get_earnings_calendar` / `get_earnings_results`，财报前1-2天不开新仓）；EPS超预期数据可用于动量延续策略但需要更长历史验证；SEC全文财报（`get_sec_filing*`）节奏太慢，本次不纳入。

**3.3 新闻与舆情层**：数据源 `get_equity_news`。1个月、4个标的的样本量不足以训练/验证情绪模型，**第一版把情绪分当过滤器而非主驱动**——技术信号触发买入但当天情绪极端负面时暂缓，不让情绪分直接触发交易。

**3.4 宏观/行业层**：SMH（半导体ETF）或 VIX 剧烈波动时暂停新开仓，只做已有仓位的风控离场。这层不产生信号，只回答"现在是否适合执行策略"。

**3.5 组合方式**：加权打分，每层给 -1到+1 分数按权重加总，超阈值触发。权重/阈值写成可调常量，记录在日志里方便复盘"哪层信号主导了这笔交易"。

## 当前取舍（为什么只做两层）
一次性堆四层会导致系统复杂到1个月内无法判断"是策略问题还是数据源问题"。**第一版只用技术面+财报避雷**，新闻情绪先做成每日生成的参考（不自动化决策）。等简单版本跑稳、逻辑说得清楚，再考虑把情绪层接入自动化决策链路。

## 风控参数的推导逻辑
- 单标的仓位≤25%：避免押注单一股票
- 止损-6%：固定比例，触发即卖，不做主观判断
- 单日最大亏损-3%：触发后当天停止交易
- 单日≤2笔：避免过度交易侵蚀本金（滑点+情绪化交易是实际风险，Robinhood本身免佣）

## 一个月后评估标准（不只看赚了多少钱）
1. 策略收益 vs 同期买入并持有 QQQ/VOO，谁更好
2. 每笔交易是否都能追溯到明确规则
3. 回撤情况，风控是否真的生效
4. 交易次数是否足够（太少则样本不足以判断策略好坏）

逻辑清晰可解释才考虑加仓；账户涨了但说不清为什么，应延长观察期而不是直接加到$10000。
